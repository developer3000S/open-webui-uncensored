# Инструкции по запуску Open WebUI

## Варианты запуска

### 1. Быстрый старт (рекомендуется)
```bash
./quick-start.sh
```
- Проверяет наличие собранного образа
- Использует готовый образ если есть
- Собирает при необходимости
- Наиболее быстрый способ запуска

### 2. Запуск через Docker Compose
```bash
./docker-compose-run.sh
```
- Использует docker-compose.yaml конфигурацию
- Поддерживает все настройки из compose файла
- Удобно для продвинутой конфигурации

### 3. Оригинальный скрипт
```bash
./docker-run.sh
```
- Оригинальный скрипт с исправленными ошибками
- Яркий информативный вывод
- Хорошая обработка ошибок

## Исправленные ошибки в скриптах

### В docker-run.sh:
1. **Использование `${IMAGE}` как имени тома** - исправлено на отдельный том `open-webui-rus_open-webui`
2. **Отсутствие создания тома** - добавлено создание тома данных
3. **Улучшенная обработка ошибок** - добавлены проверки успешности выполнения команд
4. **Информативный вывод** - добавлены понятные сообщения о ходе выполнения
5. **Проверка порта** - добавлена проверка доступности порта

### В docker-compose-run.sh:
1. **Поддержка обоих вариантов docker-compose** (старый и новый plugin)
2. **Обработка ошибок** при остановке существующих контейнеров
3. **Проверка состояния** после запуска
4. **Информативный вывод** с полезными командами

## Полезные команды для управления

### Просмотр логов:
```bash
docker logs open-webui
```

### Остановка контейнера:
```bash
docker stop open-webui
```

### Запуск контейнера:
```bash
docker start open-webui
```

### Перезапуск контейнера:
```bash
docker restart open-webui
```

### Вход в контейнер:
```bash
docker exec -it open-webui bash
```

### Просмотр томов:
```bash
docker volume ls
```

### Удаление данных:
```bash
docker volume rm open-webui-rus_open-webui
```

## Решение проблем

### 1. Сборка занимает много времени
- Первая сборка всегда долгая (10-15 минут)
- Последующие сборки используют кэш Docker
- Используйте `./quick-start.sh` для повторных запусков

### 2. Порт занят
- Проверьте другие контейнеры: `docker ps`
- Измените порт через переменную окружения:
  ```bash
  export OPEN_WEBUI_PORT=8084
  ./docker-run.sh
  ```

### 3. Ошибки сборки
- Проверьте доступ в интернет для загрузки зависимостей
- Убедитесь, что Docker запущен: `docker --version`
- Проверьте доступное место на диске

### 4. Ошибки запуска контейнера
- Проверьте логи: `docker logs open-webui`
- Убедитесь, что порт не занят
- Попробуйте удалить и пересоздать контейнер

## Настройка порта

По умолчанию используется порт **8083**. Для изменения порта:

```bash
export OPEN_WEBUI_PORT=8080
./docker-run.sh
```

или

```bash
OPEN_WEBUI_PORT=8080 ./docker-compose-run.sh
```

## Обновление

Для обновления Open WebUI:

1. Остановите контейнер:
   ```bash
   docker stop open-webui
   ```

2. Удалите старый образ:
   ```bash
   docker rmi open-webui
   ```

3. Перезапустите:
   ```bash
   ./docker-run.sh
   ```

Данные сохраняются в томе Docker и не будут потеряны при обновлении.
